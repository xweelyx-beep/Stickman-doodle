## Frame addressing

All 157 frames carry real `[MM:SS]` timestamps, `[00:00]` through `[11:22]`,
strictly increasing and ending exactly on the runtime. Four of the five
music-bed movement boundaries in `audio/music_bed_cues.md` land on a frame
exactly. `revision_changelog.md` records how the mapping was validated.

## Format

One frame per line, blank line between entries. Every frame carries three fixed
parts, and the revision pass leaves all three intact:

1. **Front style anchor** — `2D cartoon animation in modern YouTube explainer
   style, bold clean black outlines, cel-shaded flat colors with soft ambient
   shading and gentle depth,`
2. **Scene body** — including the full character lock block, restated verbatim
   with no shorthand, on every frame the protagonist appears in.
3. **End style lock** — `clean vector cartoon finish, soft natural lighting, no
   photorealism, no realistic human faces, no anime style, 16:9 aspect ratio,
   YouTube explainer animation style.`

Prehistoric frames use the cobalt blue rough-woven hide wrap variant of the
lock instead of the hoodie.

## Naming

```
image_prompts_<episode_slug>.txt      manual Nano Banana Pro queue, one prompt per shot
video_prompts_<episode_slug>.json     Seedance 1.5 Pro scene prompts
```

The slug is the episode title, lowercased, spaces to underscores.

## What the pipeline emits

`scripts/run.py prompts` writes into an episode directory, not here, using the
names fixed in `scripts/core/state_manager.py`:

| Key | File |
|---|---|
| `seo` | `01_ideation_and_seo.md` |
| `script` | `02_narration_script.md` |
| `video_prompts` | `03_kie_video_prompts.json` |
| `thumbnail_prompts` | `04_kie_thumbnail_prompts.md` |
| `metadata` | `05_metadata.md` |
| `state` | `state.json` |

This episode's prompts were authored by hand rather than generated by that
pipeline, which is why they live here under the naming above.

## Generating from these

Nano Banana Pro runs through Google Flow or Meta AI — browser surfaces with no
API this repository can reach. Nothing here submits automatically, and the
repository contains no code that calls a paid endpoint. See `docs/toolchain.md`.
