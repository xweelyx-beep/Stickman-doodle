# Memory hub

Durable context that should survive a session ending. Three surfaces, kept
apart on purpose:

| Surface | Holds | Written by |
|---|---|---|
| `memory/*.json` | live position, topic history, retention learnings | the pipeline, `scripts/core/memory.py` |
| `docs/channel-bible.md` | the channel canon | a human, when a lock is measured |
| this file | standing decisions and where things live | a human, or an agent when a decision is made |

Ported from xweelyx-beep/Business on 2026-09-02. That repo injects the
`## Standing decisions` block into every session through a SessionStart hook in
`.claude/hooks/`. **This repository has no hooks**, so nothing here loads
automatically — read it when starting work. Keep the block short anyway: it is
the part worth reading first.

## Standing decisions

- Video is **Seedance 1.5 Pro** via kie, voice is **ElevenLabs**. Locked by the
  operator 2026-08-28 in `scripts/config/models.json`. The pipeline reads these
  locks and refuses a paid stage against anything else.
- Stickman art is **Nano Banana Pro**, and the route is a manual or automated
  browser handoff, not an API this environment can call.
- Three human approval gates: script, prompts, spend. No stage skips one.
- Faceless is absolute. No face, no name, no personal identity, ever.
- Paid tools are never Claude's pick. Name options and costs, then wait.
- Cost claims in `models.json` are `verified:false` until checked against live
  pricing. Do not quote them as fact.

## What is canon here, and what is not

The canon is `docs/channel-bible.md`, and most of it is `[BLOCKED]` — the beat
architecture, the voice lock and the pace, because the two existing episodes
live on a drive this environment cannot reach. `init` and `script` refuse by
default rather than guess; `--allow-provisional-architecture`, `--voice-lock`
and `--seconds-per-scene` override each one explicitly and produce a working
draft, not canon.

**Do not fill a blocked section from imagination.** A lock invented here would
contradict footage that already exists, which is worse than no lock at all.

## Recurring decisions

Append when a decision gets made twice, or when one would be expensive to
rediscover. Newest last. Format: date, decision, why.

  deliberate fork. The layout is declared in `channel.json` and resolved by
  `scripts/core/paths.py`; a fix that matters to both repos is applied twice.
  Rationale in `scripts/README.md`.
- **2026-09-02** — `package` writes `metadata.json` alongside `05_metadata.md`.
  The markdown is what a person reads at upload time; the JSON is what a tool

## Resuming cold

```
python3 scripts/core/memory.py resume           # where the pipeline stopped
python3 scripts/run.py status --channel stickman --episode <id>
```

No hook runs these for you here. If the first is silent, there is no active
episode.
